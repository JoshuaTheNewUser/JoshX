# JoshX AI Policy

## AI-Assisted Development

AI assistants and large language models (LLMs) are **allowed** in the JoshX project.

Contributors may use tools such as ChatGPT, GitHub Copilot, and other AI assistants to:

* Write or modify code
* Explain existing code
* Debug problems
* Brainstorm features
* Research programming concepts
* Write or improve documentation
* Create tests
* Help understand build errors

## Vibe Coding

**Vibe coding is allowed in JoshX.**

Contributors may use AI to generate substantial portions of code, including complete features or files.

However, contributors are responsible for the code they submit. AI-generated code should be reviewed, tested, and checked for compatibility with the project's license and requirements.

## Contributor Responsibility

Using AI does not remove the contributor's responsibility for their contribution.

Before submitting AI-assisted work, contributors should make a reasonable effort to:

* Understand what the code does
* Test it when practical
* Check for obvious bugs
* Make sure it does not introduce security problems
* Make sure it follows the project's coding and licensing requirements

## Licensing

AI-generated code must still comply with all applicable licenses and copyright requirements.

JoshX is based on existing open-source software, so contributors must not remove or misrepresent required copyright notices, license information, or attribution.

## AI Disclosure

Contributors **do not need to disclose every use of AI**.

If a contribution is substantially generated by AI, disclosure is encouraged when it would help reviewers understand the contribution, but it is not required unless JoshX maintainers introduce a specific disclosure requirement.

## No AI Harassment

AI use is permitted regardless of which AI tool a contributor chooses.

Contributors should not be harassed, rejected, or discriminated against simply because they used AI-assisted development.

## Human Review Still Matters

AI can make mistakes.

The JoshX project welcomes AI-assisted development, but contributors should use their own judgment and test their changes before submitting them.

## Policy Scope

This policy applies to the **JoshX project** and its contributors.

It does not represent or modify the policies of upstream projects from which JoshX's code may originate.

**JoshX allows AI-assisted development and vibe coding. Have fun building! 🚀**
